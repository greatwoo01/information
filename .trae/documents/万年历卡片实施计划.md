# 万年历卡片实施计划

## Context

当前首页已有日期时间、天气和番茄计时器卡片，需要新增一个与现有 shadcn/ui 风格一致的万年历卡片，展示公历、农历，以及中国法定假期和调休上班安排。假期数据采用本地依赖计算，避免运行时依赖外部接口。

## 实施方案

1. **添加数据依赖**
   - 使用 `corepack pnpm add chinese-days` 安装依赖并更新 `package.json`、`pnpm-lock.yaml`。
   - 使用 `getLunarDate()` 获取农历日期、干支和生肖，使用 `getDayDetail()` 区分法定放假、周末调休上班和普通日期。
   - 当前法定假期/调休数据覆盖 2004—2026 年；后续国务院发布新年度安排时升级依赖。农历浏览范围限定为 1900—2100 年。

2. **新增 `src/components/PerpetualCalendar.tsx`**
   - 作为客户端组件，复用现有 `Card`、`Button`、`Skeleton` 和 `Calendar`/`CalendarDayButton`。
   - 卡片采用整行布局，桌面端显示“月历 + 选中日期详情”，移动端上下排列。
   - 每个日期格显示公历日期和农历月日；法定放假标记红色“休”，调休上班标记橙色“班”，普通周末不误标为法定假期。
   - 支持前后切月、年月下拉选择、选中日期和“回到今天”；详情区展示完整公历、农历、干支生肖及假期/调休名称。
   - 2004—2026 年之外仍显示农历，但明确提示“该年份暂无官方假期/调休数据”，不伪造假期标记。
   - 初始动态日期仅在 `useEffect` 中创建，挂载前显示固定骨架屏；日期键使用本地年月日格式，避免 UTC 跨日及 hydration 问题。
   - 自定义日期格复用 `CalendarDayButton`，内部只放置文本元素，避免嵌套按钮。

3. **接入 `src/app/page.tsx`**
   - 保持现有两列卡片布局，在网格末尾增加 `lg:col-span-2` 的万年历整行卡片。
   - 更新页面副标题和元数据描述，使其包含万年历功能，不调整现有卡片逻辑。

## 验证

- 运行 `corepack pnpm ts-check` 和 `corepack pnpm lint:build`，修复本次改动引入的问题。
- 用依赖 API 核对已知日期，例如 2026-02-15 为法定放假、2026-02-14 为调休上班，并抽查农历转换。
- 在 `http://localhost:5001` 验证：初始今天、切月、年月选择、回到今天、日期详情、“休/班”标记、无数据年份提示及移动端布局。
- 检查浏览器控制台无 hydration、类型运行错误或非法 HTML 嵌套问题。
